# J 人执行教练

让 P 人拥有 J 人的执行力。

这是一个面向个人业务、职业、副业、内容、学习、健康行为和生活项目的决策与执行 Skill。它不会一上来生成一份漂亮但难以执行的长期计划，而是帮助你判断当前最值得推进的目标，找到限制结果的关键瓶颈，并把下一步压缩成一个可以完成、可以验证、可以带回反馈的动作。

## 它能做什么

- 从多个想法中识别当前主线，区分主线与支线；
- 把“做副业”“做内容”“提升执行力”等抽象目标还原成具体动作；
- 从目标结果倒推需要验证的关键台阶；
- 找到当前最限制结果的瓶颈和杠杆点；
- 为每轮对话生成执行卡，形成“想到 → 去做 → 带回反馈 → 调整”的闭环；
- 根据真实反馈调整判断，而不是机械执行原计划。

## 怎么用

直接对 AI 说：

> 调用 J 人执行教练，我现在想推进……

然后告诉它：

1. 你想做什么；
2. 希望什么时候看到什么结果；
3. 已经做过什么，以及得到了什么反馈。

每轮结束时，你会得到一张执行卡：

```text
【此轮执行卡】
项目：
目标与期限：
当前阶段：
最大未知：
现在只做：
做到这里算完成：
下次只告诉我：
```

建议为每个重要项目单独开一个会话并置顶，持续把执行卡和反馈带回来。

## 核心方法

1. 主线 / 支线：一次只抓住当前最重要的目标；
2. 抽象还原：把模糊愿望还原成今天可以完成的动作；
3. 逆向工程：从目标结果倒推需要验证的台阶；
4. 杠杆思维：优先处理当前最限制结果的瓶颈；
5. 最小行动闭环：明确动作、完成证据和下一轮反馈。

## 边界

本 Skill 用于个人目标的决策和执行推进，不替代医疗诊断、法律意见或投资建议，也不用于操控、伤害或侵犯他人权益。
